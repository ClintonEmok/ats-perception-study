<objective>
Define the canonical burst-volume data model. Add pure TypeScript types for a burst volume and its internal temporal samples, then implement a deterministic builder that can derive the model from existing burst windows and STKDE slice data without introducing any rendering or store coupling.

Purpose: BURST-01 requires the burst to read as one analytical object; BURST-02 requires multiple temporal samples with centroid and spread evolution. This plan establishes the shared contract that later rendering and cluster-evolution work will consume.

Output: `src/lib/stkde/burst-volume.ts` with exported burst-volume types and a pure builder, a barrel export in `src/lib/stkde/index.ts`, and contract tests that lock the derived shape.
</objective>

  <action>
    Create a pure burst-volume contract module under `src/lib/stkde/` that mirrors the repo’s existing derived-model style.

    Required exports:
    - `BurstVolumeSample` for one temporal sample inside the burst
    - `BurstVolumeModel` for the derived burst artifact
    - `BurstVolumeInput` for the raw builder inputs
    - `buildBurstVolumeModel(input: BurstVolumeInput): BurstVolumeModel`

    Model shape should include at minimum:
    - `id`, `label`
    - `startEpochSec`, `peakEpochSec`, `endEpochSec`
    - `durationSec`, `eventCount`, `adaptiveHeight`
    - `samples: BurstVolumeSample[]`
    - `centroidPath` or equivalent ordered sample-centroid list
    - `spatialFootprint` or equivalent summary of the burst footprint

    Sample shape should include at minimum:
    - `timeEpochSec`
    - `centroidLng`, `centroidLat`
    - `spreadMeters`
    - `supportCount` or similar support measure
    - a stable `sampleId`/`index`

    Keep the builder deterministic:
    - sort inputs before sampling
    - cap the default internal sample count to a small fixed number (3–5)
    - return a neutral/empty model when inputs are missing

    `src/lib/stkde/index.ts` should barrel-export the new module so later rendering and inspection code can consume one stable import path.
  </action>

    - `grep -F "buildBurstVolumeModel" src/lib/stkde/burst-volume.ts` matches
  </verify>
  <acceptance_criteria>
